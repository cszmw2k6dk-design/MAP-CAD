# MAP工具箱 v2.23 (PdfLayout.lsp)

> 完整使用说明：[使用说明.md](使用说明.md)

AutoCAD LISP 插件：**识别模型空间已有图纸 → 复制模板布局 → 按可配置规则自动改名 → 每个布局视口自动对准对应图纸**。

工作方式与你现在的习惯完全一致：

1. 你用 CAD 自带功能把 PDF 导入模型空间（推荐每页勾选 **Import as block**），并手动把每张图纸摆到对应位置；
2. 插件识别模型空间里的图纸，按位置自动排序（先上后下、先左后右）；
3. 选择带图框的模板布局，设置复制数量和命名规则；
4. 插件自动复制布局、按规则改名，并让每个布局的视口对准模型里对应的一张图纸（默认不锁定显示，方便微调）。

## 安装方法

### 方法一：临时加载（单次使用）

1. 打开 AutoCAD，命令行输入 `APPLOAD`；
2. 选择 `PdfLayout.lsp`，点击「加载」；
3. 命令行出现加载成功提示即可使用。

### 方法二：启动组自动加载

1. `APPLOAD` → 「启动组」→「内容」→「添加」；
2. 选择 `PdfLayout.lsp`，关闭对话框；
3. 以后每次启动 AutoCAD 自动加载。

### 方法三：插件包安装（.bundle）

1. 把 `PdfLayout.bundle` 整个文件夹复制到：
   - `%APPDATA%\Autodesk\ApplicationPlugins\`（当前用户），或
   - `C:\Program Files\Autodesk\ApplicationPlugins\`（所有用户）；
2. 重启 AutoCAD，插件自动加载；
3. 如需卸载，删除该文件夹即可。

## 使用方法

### 命令：`PDFLAYOUT`（对话框版）

需要 `PdfLayout.dcl` 与 `.lsp` 在同一目录。

1. **图纸识别**
   - 弹窗「PDF文件」处可选择要导入的 PDF，插件自动调用 PDFATTACH 导入，再按竖线标记顺序排列；
   - 自动识别块引用：模型空间里 PDFIMPORT 导入的块会自动按位置排序，可在「块名过滤」填块名前缀精确过滤；
   - 手动一次性框选：一次框选全部图纸块，自动按从左到右、从上到下排序对应。
2. **布局**：选择模板布局（含图框的布局），设置复制数量；同名布局存在时可勾选「覆盖」。
3. **命名规则**：填写规则、字母列表、每组张数、编号起始，下方实时预览生成的名字。
4. 确定后自动完成。

### 命令：`PDFLAYOUTCMD`（命令行版）

无需 DCL，参数与对话框版一致，可脚本化使用。识别方式：A 自动识别块引用 / M 手动一次性框选全部 / K 竖线标记识别（每张 PDF 底图旁放一个标记块，按标记顺序匹配最近 PDF 底图）。

### 命令：`PDFLAYOUTTEST`（命名引擎自检）

无需图纸即可运行，自动验证命名规则引擎，输出各规则的通过/失败结果。

---

### 命令：`PDFLAYOUTDEBUG`（视口适配调试）

输入后开/关调试输出，再执行 PDFLAYOUTCMD，命令行会打印每张图纸和视口的适配参数（图纸尺寸、视口尺寸、比例、视图高），用于排查"布局里图纸偏大/偏小、没对准"等问题。

---

### 命令：`PDFRENAME`（多行文字按顺序命名）

框选一个区域内的多行文字（MText），选择排序方式后，按顺序把文本内容改为“前缀 + 编号”，例如 STR1、STR2 … STR40。支持两种排序：1-从左到右再从上到下、2-从上到下再从左到右；可设置前缀、起始编号、编号位数（补零），执行前有名称预览和确认。

---

### 命令：`PDFRENAME`（多行文字按顺序命名）

框选一个区域内的多行文字（MText），选择排序方式后，按顺序把文本内容改为对应名称。支持八种排序组合（主方向×次方向）：1-左→右再上→下、2-上→下再左→右、3-右→左再上→下、4-下→上再左→右、5-左→右再下→上、6-右→左再下→上、7-上→下再右→左、8-下→上再右→左；弹出「命名方案」对话框，所有参数用鼠标设置：名称来源（自动生成/LBD标签导入）、前缀、起始编号、位数、排序方式，实时显示数字网格排序示意图和名称预览，确认后执行。弹窗参数（前缀/起始编号/位数/排序方式/名称来源）会自动记忆，下次打开自动带入，保存在 PdfLayout.ini（LSP 同目录，可手动编辑）。改名时只改文字内容，字高/文字色/背景遮挡保持原样不动（改名模式下相关控件自动灰显）。支持「方案预设」：把整组设置存成方案，下拉一键切换。

名称来源可选：

- 自动生成：前缀 + 编号，如 STR1、STR2 … STR40（可设前缀、起始编号、编号位数补零）；
- 从 CSV 导入（LBD 标签两列）：选择含 LBD 编号和标签列（如 LCA、LCB）的 Excel/CSV，自动按编号排序并把每行标签合并为 `LCA/LCB` 写入对应多行文字。

### 命令：`PDFQUICKCOPY`（快速复制：基准点=文字中心，并逐列递增）

框选要复制的一组对象（如一整排 STR1），以**第一个多行文字的中心**为基准点。复制时会询问「编号是否递增? (Y=是 / N=否)」：

- 选 **Y（递增）**：从文字中心起步，**移动鼠标实时预览下一个编号（如 STR2）会落的位置**，点一下就落定一排并整排 +1（STR1 → STR2 → STR3…），回车/Esc 结束；拖拽时**跟随中望 F8 正交开关**（开则水平/垂直吸附，关则任意方向）；
- 选 **N（不递增）**：保持原「输几列(含原对象) + 输列距」的纯复制，不改编号。

编号位数沿用源文字的格式（STR1 / STR01）。

---

### 命令：`PDFBRUSH`（刷内容）

选一个源文字，再把其他文字的内容刷成源内容——相当于"只刷内容的特性匹配"。可刷的对象：多行文字(MTEXT)、单行文字(TEXT)、块属性值(ATTRIB)、尺寸标注文字(DIMENSION)、多重引线(MULTILEADER)、旧式引线(LEADER)、形位公差(TOLERANCE)、表格单元格(ACAD_TABLE)。

操作：

1. 命令行输入 `PDFBRUSH`，点选一个文字作为源，命令行回显源内容；
2. 选刷法：
   - `回车` = 逐点连续刷：点一个刷一个，回车或 Esc 结束；
   - `W` = 框选批量刷：框选一整片文字一次刷完；块参照和表格请用逐点点选；
   - `P` = 纯文本开关：把 MTEXT 的 `\A1;` `\H` `\C` 这类内联格式码剥掉，只刷字面文字；
   - `K` = 连外观一起刷：源文字的样式/字高/颜色一起复制（默认只刷内容）；
   - `P`、`K` 两个开关会记进 PdfLayout.ini，下次自动带出。
3. 结束时命令行给出"已刷 n 个，跳过 n 个"；整轮算一步，输入 `U` 一次全部撤销。

注意事项：

- 默认只改内容，目标的位置、图层、字高、颜色都不动；刷到单行文字或标注上时会自动剥掉格式码，避免出现 `\A1;` 乱码；
- 块定义里的文字（块内文字）不会被刷，点选到只提示并跳过；块属性值可以刷，只影响当前这个块参照；
- 标注用的是测量值（没设文字替代）时不能当源，会提示重新选择；
- 表格按点到哪个单元格就刷哪个单元格。

## 命名规则说明

规则由固定文字 + 占位符组成：

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{G}` / `{G2}` | 编号段：循环完成后自动 +1，数字位数缺省 2 | `{G2}` → 01、02… |
| `{L}` | 字母段：循环使用字母列表 | 列表 `AB` → A、B、A… |
| `{N}` / `{N2}` | 序号段：每组从 1 开始，数到"每组张数"后换下一字母/编号 | `{N2}` → 01、02… |

**规律**：序号数到"每组张数"后换下一个字母；字母用完后编号 +1，一直重复。

### 示例

| 规则 | 字母列表 | 每组张数 | 生成的布局名 |
|------|----------|----------|--------------|
| `INV{G2}{L}{N2}` | `AB` | 6 | INV01A01…A06, INV01B01…B06, INV02A01… |
| `图{N2}` | 任意 | 任意 | 图01, 图02, 图03… |
| `A-{N3}` | 任意 | 任意 | A-001, A-002, A-003… |
| `{G2}{L}` | `A-Z` | 1 | 01A, 01B, 01C… |
| `DWG{G1}-{N1}` | 任意 | 3 | DWG5-1, DWG5-2, DWG5-3, DWG6-1… |

字母列表支持 `AB`（逐个字符）和 `A-Z`、`A-F` 等范围写法。

## 常见问题

**Q: 自动模式识别不到图纸？**
A: 需要 PDFIMPORT 导入时勾选「Import as block」（每页一个块）。如果之前导入的是散开的线条，自动/手动模式都无法按块拆分，请重新按块导入；也可以用「块名过滤」只统计指定前缀的块。

**Q: 图纸顺序是怎么定的？**
A: 自动模式按包围盒中心位置排序：先上后下、先左后右（Y 大者在前，Y 相同按 X 小者在前）。手动模式：一次框选全部后按从左到右、从上到下排序（X 小者在前，X 相同按 Y 大者在前）。

**Q: 每个布局的视口对应哪张图？**
A: 第 i 个布局对应排序后第 i 张图纸。视口自动缩放完整显示该图纸，默认不锁定，可随时微调；如需防误操作，可在对话框勾选「锁定视口显示」或生成后选中视口开启显示锁定。

**Q: 模板布局没有视口怎么办？**
A: 工具会让你在模板布局里点取图框的两个对角，按图框创建视口；直接回车则按纸张边距创建。

**Q: 可以覆盖已存在的同名布局吗？**
A: 勾选「覆盖同名布局」即可；不勾选时遇到重名会中止并提示。

**Q: 支持哪些 AutoCAD 版本？**
A: 支持 AutoCAD 2018 及以上版本。

## 注意事项

1. 使用前建议先保存文件（工具也支持 `UNDO` 撤销，出错时自动删除已创建的布局）；
2. 布局名称不能包含 `<>/\" : ; ? * | , =` 等字符，规则中请避免；
3. 模板布局建议保留图框和打印设置，复制后会原样带入每个新布局。
4. `PdfLayout.lsp` / `PdfLayout.dcl` 为 **GBK 编码**，确保中文版 AutoCAD 显示正常；如果用编辑器查看出现乱码，请以 GBK/GB2312 编码打开（VS Code 右下角切换编码）。
